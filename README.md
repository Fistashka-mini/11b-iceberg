# 11-Б · Айсберг одноклассников (2015 — 2028)

3D-айсберг, по которому спускаешься скроллом: над водой — «Поверхность», дальше — всё глубже.
На айсберге висят аватарки одноклассников: при наведении — имя, при клике — отдельная страница
с текстом, фактами и фото.

## Запуск

Один раз:

```bash
npm install
```

Дальше каждый раз:

```bash
npm run dev
```

Откроется `http://localhost:5173`. Всё, что меняешь в файлах, сразу обновляется в браузере.

## Как добавить одноклассника

Правится только один файл: **`src/data/classmates.js`**.

1. Положи фото в папку `public/photos/` (например `public/photos/ivan.jpg`).
2. Добавь объект в массив `CLASSMATES`:

```js
{
  id: 'ivan',                 // латиницей, без пробелов — попадает в адрес #/ivan
  name: 'Иван Иванов',
  nickname: 'человек-легенда', // необязательно
  tier: 1,                    // уровень: 0 — Поверхность, 1 — Мелководье, 2 — Глубина, ...
  angle: -30,                 // где по горизонтали: 0 по центру, от -70 до 70 — левее/правее
  offset: 0.3,                // необязательно: чуть выше (до 1) или ниже (до -1) внутри уровня
  photo: 'photos/ivan.jpg',
  about: `Первый абзац.

Второй абзац — просто через пустую строку.`,
  facts: ['Короткий факт', 'Ещё один'],   // необязательно
  gallery: ['photos/ivan-1.jpg', 'photos/ivan-2.jpg'], // необязательно
},
```

Если поле `photo` пустое — на айсберге будет кружок с инициалами.

Три примера (`primer-1`, `primer-2`, `primer-3`) в файле можно удалить.

## Уровни айсберга

Там же, в `TIERS`, можно переименовать уровни или добавить новые. Первый уровень всегда над водой,
остальные распределяются под водой автоматически. Высота прокрутки подстраивается сама.

Заголовок сайта (класс, годы, подпись) — в `CLASS_INFO`.

## Выложить в интернет

```bash
npm run build
```

Готовый сайт появится в папке `dist/` — её можно залить на GitHub Pages, Netlify, Vercel или любой хостинг.

## Структура

```
src/
  data/classmates.js  ← одноклассники, уровни, заголовок (править здесь)
  main.js             ← точка входа, связывает сцену и интерфейс
  scene.js            ← камера, свет, туман, маркеры, наведение
  iceberg.js          ← форма айсберга (низкополигональная, с шумом)
  water.js            ← шейдер воды (волны, блики, вид снизу)
  sky.js              ← небо с солнцем
  particles.js        ← снег над водой, планктон под водой
  shafts.js           ← солнечные лучи под водой
  avatar.js           ← круглые аватарки (фото или инициалы)
  ui.js               ← заголовок, подписи уровней, подсказка, страница одноклассника
  style.css
public/photos/        ← сюда складывать фото
```
